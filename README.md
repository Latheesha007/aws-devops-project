# AWS DevOps Project

## Project Overview
This project demonstrates hosting a static website using Amazon Web Services (AWS).

## Technologies Used
- AWS S3
- AWS IAM
- Git
- GitHub
- HTML
- Linux

## AWS Deployment
1. Created an S3 bucket.
2. Uploaded the website's index.html file.
3. Enabled static website hosting.
4. Configured public read access.
5. Tested the website using its S3 website endpoint.

## Project Files
- index.html - Website homepage
- README.md - Project documentation

## Future Improvements
- Automate deployment using CI/CD.
